# UV 与贴图规则

仅在处理 UV 和纹理时读取。依据 [概念图、材质与运动结构](concept-material-motion.md) 的材质表分配 UV 并验收参考一致性。

- 每个材质区保留对应的基础色、像素明暗、图案与细节方向；调整分辨率时优先保留标志特征，并记录无法实现的参考效果。
- 独立运动件的表面与附属细节须映射到正确部件；补齐打开或拆卸后露出的内侧与背面。共享图集不影响独立运动，但无意重叠可能妨碍配件替换。

- 先确认工程允许的 UV 模式和纹理分辨率。64×64 或 128×128 可作为小型资产的起始候选，按资产大小和风格调整，不能当作固定要求。
- 为各部件保持相近的像素密度；重要的脸部、符号等区域可分配更多空间。对齐像素网格，避免无意的半像素边界。
- 整理面/UV 岛映射，包括部件、面朝向、纹理坐标、旋转/镜像和用途。能从 MCP 获取实际坐标时优先读取，不凭猜测绘制。
- 区分有意共享纹理和无意重叠。非对称脸部、文字、左右装备通常需要独立区域；共享区域会限制后续差异化编辑。
- 留白和边缘扩展按采样、缩放及 mipmap 需求确定。像素画避免无意抗锯齿；透明面检查边缘杂色与目标运行时的渲染行为。
- 通过实际工具完成模板、布局、绘制与导入。缺少自动打包能力时，可逐面指定坐标或使用用户允许的原生流程，不假设所有 MCP 都提供 UV 自动展开。
- 用临时方向标记或棋盘纹理检查朝向、拉伸和接缝，然后换成最终纹理。查看正面、背面、两侧和关键关节，检查眼睛、徽记等是否落在正确表面。
- 已上色后调整布局，必须同时处理像素迁移；迁移不能可靠完成时保留旧版本，重新绘制受影响区域并验证。

按目标运行时检查透明、半透明、背面可见性和光照；已有基准贴图需同时查看中性光照与适用使用视角。面优化前保存检查点，活动或拆卸后可能露出的面必须保留。

验收依据：映射与图案对应、重叠有解释、像素密度合理、接缝可接受、透明区域正确、工程及导出资源能找到纹理。仅有一张平面贴图不足以证明验收完成。
